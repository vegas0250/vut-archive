# Архитектура Archive

Archive — приложение VUT. Оно архиватор, а не часть файлового менеджера и не источник визуальных правил.

```text
Visual / UI system     → VUI
Application capability → этот репозиторий
Desktop / OS           → Electron: окно и системные диалоги выбора файлов
OS-specific behavior   → нет своей развилки. Пути идут через node:path
```

## Граница

VUI даёт оболочку, панель команд, таблицу, пустое состояние, кнопки и тему. Archive даёт смысл строк: имя записи ZIP, размер, извлечение и создание.

Vortex сюда не импортируется. Общий низкоуровневый пакет не заводится, пока он не нужен больше чем одному месту и не оправдывает отдельную публикацию.

Локальный CSS только заполняет окно. Цвета и плотность — атрибуты VUI `system` и `compact`.

## Формат

Сейчас реализован один формат, ZIP:

```text
bytes → центральный каталог → список записей
bytes → fflate → файлы на диске
файлы на диске → fflate → ZIP
```

Список строится по центральному каталогу и не распаковывает данные. Распаковка проверяет `..`, абсолютные пути и предел 256 МБ. Следующий формат добавляется рядом с ZIP, а не внутрь таблицы.

## Electron

Renderer не получает Node. Preload отдаёт четыре вызова: выбрать путь, открыть, извлечь, создать. Main проверяет пути и расширения.

`nodeIntegration` выключен, `contextIsolation` и `sandbox` включены. `fflate` и VUI вшиты в бандлы, поэтому production-пакет не содержит `node_modules`.

## Чего нет намеренно

Своего файлового менеджера, UI-компонентов, темы, 7z, tar, ZIP64 и общего репозитория с Vortex.
